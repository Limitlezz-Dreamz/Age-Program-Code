# M4 — Dashboard, Detections, Event detail

## What works

- **Dashboard**: severity cards (click → filter Detections), detections-over-time sparkline, top rules/hosts/users/tactics, evidence stats, coverage warnings (no Sysmon, 4688 without CommandLine, missing 4104, dirty files); respects global filter
- **Detections**: virtualized server-paged list (`@tanstack/react-virtual`), sort, global filter, group-by, bulk triage, right-click filter-in/out, detail drawer with author / MITRE / FP notes / linked events
- **Event detail**: fields (text-only), raw JSON, rendered XML (escaped), related detections, decoded tab for base64/PowerShell `-enc` UTF-16LE
- **IPC**: `dashboard_summary_cmd`, `query_detections_cmd`, `get_detection_cmd`, `get_event_cmd`, `set_triage_cmd`
- **Store**: `dashboard_summary`, expanded `DetectionQuery`, `get_detection`, `get_event`, `set_triage`
