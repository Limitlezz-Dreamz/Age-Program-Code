# M1 — Ingest, normalize, store (headless)

## What works

- **`lw-ingest`**: recursive discovery (`.evtx` + `ElfFile\0` magic), optional SHA-256, read-only open, parallel parse via `evtx` + rayon, per-file error capture, cancellation token
- **`lw-normalize`**: Section 6 rules 1–4 (both JSON attribute shapes, UserData, unnamed Data[], missing timestamps, field aliases, user/IP/logon extraction)
- **`lw-store`**: SQLite case DB (`*.lwcase`), writer thread, batch inserts (zstd raw JSON), dictionary tables, finalize indexes + optional FTS, paged `query_events` + `stats_summary`
- **`lw` CLI**: `lw ingest <paths…> --case <dir>` and `lw stats --case <dir>`
