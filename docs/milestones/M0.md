# M0 — Scaffolding and CI

## What works

- Cargo workspace compiles: all `lw-*` crates + `src-tauri` + `lw` binary
- Frontend Vite/React app renders **Logwarden** branding (dark Tailwind theme)
- `just ci` runs: rustfmt check, clippy `-D warnings`, `cargo test`, `cargo deny check licenses`, `tsc`, eslint, vitest
- CI workflow matrix: ubuntu-latest, windows-latest, macos-14
- Release workflow is a stub for M7 packaging
- Fixture fetch scripts exist (datasets not committed)
