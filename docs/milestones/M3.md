# M3 — GUI shell, cases, ingest UX

## What works

- **App shell**: left nav, top case/run status, global filter bar (state only), UTC/local toggle display
- **Case home**: create/open/recent cases, add files/folder via dialog, drag-and-drop onto the window, analysis options, start/cancel, live progress + per-file status table
- **Settings**: timezone, threads, FTS/hash/profile defaults, correlation threshold fields, About/DRL note
- **IPC**: Tauri commands for case/ingest/settings; progress via `Channel<IngestProgressMsg>`; DTOs in `src/ipc/types.ts` (ts-rs feature available)
- Placeholder screens for Dashboard / Detections / Timeline / Explorer / Pivots / Rules / Export (M4+)

## Demo

```bash
npm install
cargo build -p logwarden

```

Or headless path still works:

```bash
./target/release/lw ingest … --case /tmp/demo.lwcase
./target/release/lw hunt --case /tmp/demo.lwcase
```
