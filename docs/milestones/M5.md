# M5 — Timeline, Explorer, Pivots

## What works

- **Timeline**: stacked histogram (severity or channel) with drag-brush → global time filter; jump-to-time; virtualized merged detection/event list with per-host lane color
- **Explorer**: FTS text + structured field filters (equals/contains/starts/ends/in/exists/regex≈contains); virtualized results; saved searches in case DB; event detail drawer
- **Pivots**: Hosts / Users / Source IPs with detection severity counts; Logons (A002) with type names (2 Interactive … 11 CachedInteractive); click row → filter case
- **Store/IPC**: `timeline_histogram`, `timeline_list`, expanded `query_events`, `query_pivots`, `logon_summary`, saved_searches CRUD
