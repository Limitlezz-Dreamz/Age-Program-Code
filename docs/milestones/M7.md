# M7 — Packaging and release

## What works

- **Bundle config**: deb / AppImage / NSIS / MSI / DMG / app; icons; short/long descriptions; identifier `io.logwarden.app`
- **Resources**: mappings, builtins, MITRE, event descriptions embedded; runtime via `LOGWARDEN_RESOURCES`
- **App data**: Tauri `app_data_dir` → `LOGWARDEN_DATA_DIR` (settings, packs, recent cases); Windows `LOCALAPPDATA` fallback for CLI
- **macOS**: ad-hoc signing identity `-` so unsigned CI builds are not “damaged” on Apple Silicon
- **Release workflow**: `tauri-action` matrix (macOS arm/intel, Ubuntu 22.04, Windows) → draft GitHub Release on `v*` / workflow_dispatch
- **About**: Settings shows live `app_version` from the backend

## Verification

| Check | Result |
|---|---|
| `just ci` | required green |
| Resource resolve with `LOGWARDEN_RESOURCES` | unit/dev |
| `just bundle` / Release workflow | platform runners |
| Draft release assets attached | after tagging `v*` |
