# M2 — Rules and detection (headless)

## What works

- **`lw-rules`**: Sigma YAML load (folder/zip), SigmaHQ release download (GitHub API), pack manifest + blake3, default/all/high profiles (correlation base rules retained), `logsource-windows.yml` mapping
- **`lw-detect`**: `DetectionEngine` + `RsigmaEngine` (`rsigma-eval` 0.23), event-time correlations (`TimestampFallback::Skip`, `@timestamp`), built-ins B001–B027, analyzers A001 (gaps) / A002 (logon summary), summaries, dedup, `hunt()` orchestration
- **`lw-store`**: run rows, detection inserts + event links, ordered event iteration for re-detect (no re-parse)
- **`lw` CLI**: `lw hunt --case <dir> [--rules …] [--profile default|all|high]` and `lw detections --case <dir> --format table|json`

## Demo

```bash
cargo build -p lw-cli --release
CASE=/tmp/m2-demo.lwcase
./target/release/lw ingest tests/fixtures/cc0/sample.evtx --case "$CASE" --no-hash --no-fts
./target/release/lw hunt --case "$CASE" --profile all
./target/release/lw detections --case "$CASE" --format table
```

With attack samples:

## Notes

- SigmaHQ packs are **not** committed; download at runtime (`lw-rules::download_sigma_pack`) under DRL 1.1 with author attribution on matches.
- Re-hunt iterates SQLite events only — EVTX is not re-parsed.
