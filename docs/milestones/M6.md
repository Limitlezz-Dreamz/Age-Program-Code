# M6 — Rules manager + exports

## What works

- **Rules**: list imported packs; import directory/zip; download SigmaHQ (core/emerging) at runtime; enable/disable rules; suppressions (field/value); rule detail (YAML + metadata); re-run detection with profile + builtins
- **Store**: `rules` / `suppressions` tables; upsert on pack import; hunt skips disabled rules and applies suppressions
- **Export**: CSV / JSON / JSONL / HTML with rule author + source; offline HTML embeds DRL + MITRE notices (no remote assets)
- **CLI**: `lw export --case … --format csv|json|jsonl|html -o path`
- **IPC/UI**: Rules + Export screens (nav live; no “soon” placeholders)
